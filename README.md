# Titanic — خط أنابيب تنظيف بيانات متكامل (Messy → Modeling-Ready)

مشروع كامل يأخذ نسخة **فوضوية متعمّدة** من بيانات Titanic (تكرارات + قيم مفقودة +
تناسق نصوص فوضوي + جدول منفصل للدمج) ويحوّلها إلى داتاسيت نظيف جاهز 100% للنمذجة.

كل الخلايا منفّذة والرسومات والنتائج ظاهرة داخل النوتبوك.

## الملفات

- **`titanic_full_cleaning_pipeline.ipynb`** — النوتبوك الكامل (الخطوات 1-6).
- **`titanic_full_cleaning_pipeline.html`** — نسخة HTML للعرض بالمتصفح مباشرة.
- **`titanic_clean_ready.csv`** — الداتاسيت النهائي النظيف (780 صفًا فريدًا، كل الأعمدة رقمية).

## الخطوات

1. **تجهيز البيانات الفوضوية:** إنشاء `messy_titanic` (906 صف) + جدول `class_info`.
2. **EDA قبل التنظيف:** الشكل العام، القيم المفقودة ونسبها، التكرارات (120 صفًا)،
   فحص تناسق `embark_town`، و**3 رسومات** (توزيع الأعمار، النجاة حسب الفئة،
   السعر مقابل العمر) مع تفسير تحت كل رسمة، ثم ملخص المشاكل.
3. **التنظيف:** حذف التكرارات، توحيد `embark_town` بـ Title Case، تعويض `age`
   بالوسيط و`embarked`/`embark_town` بالمنوال، حذف `deck` (77% مفقود)، مع التحقق.
4. **الدمج:** `left merge` مع `class_info` على `pclass` (إضافة `class_description`
   و`deck_access`).
5. **Encoding / Scaling / Feature Engineering:** Label لـ `sex`، One-Hot للأعمدة
   متعددة الفئات، ميزتان جديدتان (`family_size`, `fare_per_person`)، و`StandardScaler`.
6. **التوثيق النهائي:** جدول القرارات، مقارنة الأبعاد قبل/بعد، تأكيد (بلا مفقودات/
   تكرارات/أعمدة نصية) عبر `assert`، وحفظ `titanic_clean_ready.csv`.

## ملاحظات مهمة (اكتُشفت أثناء التنفيذ)

- الداتاسيت الأصلي يحوي **~107 صفًا مكررًا طبيعيًا** إضافةً إلى الـ15 المضافة عمدًا،
  لذلك ظهر 120 صفًا مكررًا.
- بعد **تقليص الأعمدة** تطابقت بعض الصفوف في مساحة الميزات المصغّرة، فاحتجنا إزالة
  تكرار **على مرحلتين** للوصول إلى صفوف فريدة تمامًا.

## الناتج النهائي

`titanic_clean_ready.csv`: 780 صفًا × 18 عمودًا، جميعها رقمية، بلا أي قيمة مفقودة
أو صف مكرر — جاهز مباشرةً للنمذجة.
